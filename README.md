## Overview

This repository documents my progress through the Object-Oriented Programming course. It contains:

- **Lab solutions**: completed weekly lab tasks, organized by lab number.
- **Practice questions**: additional problems solved for concept reinforcement and exam preparation, grouped by topic.

Every program is self-contained and includes comments explaining the reasoning behind key design decisions.

---

## Concepts Covered

| Concept | Description |
|---|---|
| **Classes & Objects** | Defining blueprints and creating instances |
| **Constructors & Destructors** | Object initialization and cleanup |
| **Encapsulation** | Data hiding, getters/setters, access modifiers |
| **Inheritance** | Single, multilevel, hierarchical, and multiple inheritance |
| **Polymorphism** | Method overloading, overriding, and runtime dispatch |
| **Abstraction** | Abstract classes and interfaces |
| **Operator Overloading** | Custom behavior for operators on user-defined types |
| **Static Members** | Class-level data and methods |
| **Composition & Aggregation** | "Has-a" relationships between classes |
| **Exception Handling** | Writing robust, error-tolerant code |
| **File Handling** | Persisting object data to files |

> Adjust this table to match the topics your course actually covered.

## Practice Questions

Practice problems are grouped by concept so you can target specific weak areas:

- **Classes & Objects**: modeling real-world entities (student, account, product)
- **Encapsulation**: validation, controlled access, immutable objects
- **Inheritance**: class hierarchies and code reuse
- **Polymorphism**: overriding, virtual functions, dynamic behavior
- **Abstraction**: abstract base classes and interface-driven design
- **Mixed / Exam-style**: multi-concept problems that combine the topics above

## Getting Started

### Prerequisites

- [Language] compiler or interpreter installed
- Git
- Any code editor or IDE (VS Code, CLion, IntelliJ, PyCharm, etc.)

### Clone the Repository

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
```

### Run a Program

Pick the command that matches your language:

| Language | Command |
|---|---|
| **C++** | `g++ file.cpp -o output && ./output` |
| **Java** | `javac File.java && java File` |
| **Python** | `python file.py` |

## Coding Standards

- Meaningful class, method, and variable names
- One concept per file wherever practical
- Comments that explain *why*, not just *what*
- Consistent formatting and indentation
- Input validation and clear output messages
